# Dữ liệu TikTok (nếu tổ chức có dùng)

Cần đăng nhập tài khoản TikTok của tổ chức. Tài khoản phải là **tài khoản Doanh nghiệp hoặc Nhà sáng tạo** thì mới có phân tích.

## Cách tải
1. Vào https://www.tiktok.com/tiktokstudio trên máy tính.
2. Menu trái: **Phân tích** (Analytics) → tab **Nội dung** (Content).
3. Chọn khoảng thời gian (7, 28, 60 ngày hoặc tùy chỉnh).
4. Bấm **Tải xuống dữ liệu** (Download data). TikTok cho tải file `.xlsx` hoặc `.csv`.
5. Nếu là `.xlsx`: mở bằng Excel → **File → Save As → CSV UTF-8**.
6. Lưu file `.csv` vào thư mục này.

## Cột script cần
Video title · Post time · Total views · Total likes · Total comments · Total shares.

Nếu tổ chức không dùng TikTok, để trống thư mục này. Báo cáo sẽ ghi "Chưa có dữ liệu".
